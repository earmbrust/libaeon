Introduction
============

libaeon is designed to be:

- **Simple**: Easy-to-use API for TCP/UDP socket programming
- **Lightweight**: Minimal dependencies, small footprint
- **Cross-Platform**: Works on Windows, Linux, macOS, and ARM
- **Portable**: Same code compiles on all supported platforms

Features
--------

- TCP client and server sockets
- UDP datagram sockets
- Event-driven socket handling
- Non-blocking I/O support
- Timeout support for read/write/connect operations
- Socket sets for managing multiple connections
